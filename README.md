# ラッキーブロックを打つ Web（非公式ファンメイド） v0.13

Roblox「Launch a Lucky Block（Lucky Bear Studio）」を題材にした、ブラウザで遊べる 3D ゲームです。
HTML / CSS / JavaScript と [three.js](https://threejs.org/) で作っています。

## あそびかた

1. 💪 力は放置で増えます。ダンベルの上に立つと 3 倍、行動ボタンでさらにボーナス。
2. 🏏 黄色い発射台でラッキーブロックを打ちます。タイミングゲージで PERFECT を狙うと飛距離アップ。
3. 📦 遠くのゾーンほどレアなキャラが出ます。落ちた場所でブロックを開けましょう。
4. 👹 ゾーンのボスが追ってきます。拠点（緑のライン）まで逃げ切ればキャラを台座に設置。
5. 💰 キャラは毎秒お金を稼ぎます。台座に触れて回収し、ダンベル・スピードの強化やキャラの進化に使います。
6. 📖 一度持ち帰ったキャラは「インデックス」（図鑑）に登録されます。

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 左下のジョイスティック |
| 行動 | 左クリック / E / スペース / Enter | 右下のボタン |
| 視点 | クリックでマウスロック → マウス移動（Esc で解除）・ホイールでズーム | 画面をスワイプ |

## ローカルで動かす

ES Modules を使っているので、ファイルを直接開くのではなく簡易サーバー経由で開いてください。

```bash
python -m http.server 8000
```

## オンラインランキング（準備中）

Supabase に `public.llb_scores` テーブルと `public.llb_submit_score` RPC を用意済みです。
クライアント側の送信・取得処理は `js/ranking.js` にあります（まだゲームからは呼んでいません）。
