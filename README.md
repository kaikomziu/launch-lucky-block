# ラッキーブロックを打つ Web（非公式ファンメイド） v0.42

Roblox「Launch a Lucky Block（Lucky Bear Studio）」を題材にした、ブラウザで遊べる 3D ゲームです。
HTML / CSS / JavaScript と [three.js](https://threejs.org/) で作っています。

## あそびかた

1. 💪 力は放置で増えます。ダンベルの上に立つと 3 倍、行動ボタンでさらにボーナス。
2. 🏏 黄色い発射台でラッキーブロックを打ちます。タイミングゲージで PERFECT を狙うと飛距離アップ。
3. 📦 遠くのゾーンほどレアなキャラが出ます。落ちた場所でブロックを開けましょう。
4. 👹 ゾーンのボスが追ってきます。拠点（緑のライン）まで逃げ切ればキャラがインベントリに入ります。空いている台座に近づくと、置くキャラを選べます（台座のキャラはインベントリにしまうこともできます）。「⭐ 一番いいキャラを装備する」を押すと、稼ぎの多いキャラから自動で台座に並びます。
5. 💰 キャラは毎秒お金を稼ぎます。台座に触れて回収し、ダンベル・スピードの強化やキャラの進化に使います。
6. 📖 一度持ち帰ったキャラは「インデックス」（図鑑）に登録されます。通常・ゴールド・ダイヤ・ギャラクシーのタブに分かれていて、変異のタブを75%集めると拠点の地面をその色に変えられます。
6.5 🧬 15分ごとに3分間の「変異イベント」があります。その間にブロックから出たキャラは全員変異し（ゴールド ×2・ダイヤ ×3・ギャラクシー ×5）、見た目が変わって稼ぎが増えます。イベントの時間は時計で決まるので、だれでも同じタイミングです。
6.6 🗺️ ゾーンは全24か所（全長約5,300m）。遠くなるほど長くなります（草原80m → 虹の果て356m）。日本・ジャングル・お菓子の国・海賊の島・恐竜の谷・ネオン街・天空城・お化け屋敷・虹の果てなど、ゾーンごとに景色とボスが違います。
6.7 💨 ダッシュ（PCはShift、スマホは💨ボタン）で少しの間速く走れます（3秒ごと）。ショップの「飛ばす力」で飛距離を下げて、逃げ切れるゾーンを狙うこともできます。
6.8 ✨ 各ゾーンに1体ずつ、1%でしか出ない激レアキャラ（稼ぎ ×3）がいます。
7. 🔄 お金がたまったらショップで「リボーン」。お金・力・ダンベル・スピードが最初に戻る代わりに、稼ぎと力の伸びが 1 回ごとに +50% 増えます（キャラとインデックスは残ります）。

かるわかGAMESアカウントでログインすると、セーブがクラウドに保存され、別の端末でも続きから遊べます（タイトル画面か設定から）。

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 左下のジョイスティック |
| ダッシュ | Shift（3秒ごと） | 💨ボタン |
| 行動 | 左クリック / E / スペース / Enter | 右下のボタン |
| 視点 | クリックでマウスロック → マウス移動（Esc で解除）・ホイールでズーム | 画面をスワイプ |
| メニュー | 1〜4 キー（ショップ・インベントリ・インデックス・設定） | 右上のボタン |

## ハロウィンイベント（10/1〜11/10）

- 空が夕暮れの紫になり、ジャック・オ・ランタンとコウモリが出ます。
- 変異に「🎃 かぼちゃ」（×4・キャラの頭にかぼちゃが乗る）が加わります。
- 10分ごとに1分間の「レインボーかぼちゃタイム」中に手に入れたキャラは、ごくまれに（3%）「🌈 レインボーかぼちゃ」（×7）になります。
- インデックスにかぼちゃ・レインボーかぼちゃのタブがあり、75%集めると拠点をその色にできます。

## 管理者メニュー

かるわかGAMESの管理者アカウント（`ka_accounts.is_admin`）でログインすると、右上に「🛠 管理者メニュー」が出ます（PCは7キーでも開けます）。
全員へのメッセージ、キャラクター配布（1人1体）、変異イベントの開始（最長10分）ができます。配布と変異イベントでは、かぼちゃ・レインボーかぼちゃも選べます。どれも「⏰ 予約する」で開始日時を指定できます（30日先まで、始まる前なら取り消し可）。
権限の確認と値の検査はサーバー（Supabase の `llb_admin_post` など）で行い、お金や力のようにゲームが壊れるものは配れません。

## ローカルで動かす

ES Modules を使っているので、ファイルを直接開くのではなく簡易サーバー経由で開いてください。

```bash
python -m http.server 8000
```

## フレンドと一緒に遊ぶ

右上の「👥 フレンド」（PCは9キー）から。かるわかGAMESアカウントでログインすると使えます。
- 相手のID（ユーザー名）で申請 → 相手が承認するとフレンドになります。
- 「部屋を開く」と、フレンドの一覧に「🏠 部屋を開いています」と出て、フレンドが「参加」できます（最大4人）。
- つながると WebRTC で端末どうしが直接通信し、おたがいの姿・名前・持っているキャラが見え、持ち帰り・リボーンを知らせ合えます。セーブはそれぞれ別です。
- Supabase は、フレンドの一覧（90秒ごと、ログイン中だけ）と、つながるまでの取り次ぎ（部屋を開いている間・参加しようとしている間だけ）にしか使いません。
- STUN だけを使っているので、学校や会社などの一部の通信環境ではつながらないことがあります。

## グローバルチャット

右上の「💬 チャット」（PCは「/」か8キー）で全員とチャットできます。1発言100文字まで、3秒に1回・1分に8回まで。
かるわかGAMESアカウントでログインすると名前に ✔（管理者は 🛠）が付きます。管理者は発言を消せます。
通信を節約するため、新しい発言の読み込みはチャットを開いている間だけ（4秒ごと）。閉じている間の未読は、同時接続の知らせ（2分ごと）で分かります。

## 同時接続数

タイトル画面と右上に、いま遊んでいる人数が出ます。画面が見えている間だけ2分ごとに1回知らせる軽い仕組みです
（Supabase の `llb_online` と `llb_ping`。3分以内に知らせた人を数える）。

## バックアップ

セーブは自動でバックアップされます。このブラウザに最新6件（1分ごと）、かるわかGAMESアカウントでログインしていればクラウドに最新20件（10分ごと）。
データが最初からになっていて前のデータが見つかると、復元を勧める画面が出ます。設定の「💾 バックアップから復元」からも戻せます。
リセットする前のデータもバックアップに残ります。

## スキン

右上の「👕 スキン」（PCは6キー）で、プレイヤーの見た目を12種類から着がえられます。
キャラを持ち帰る・インデックスを集める・リボーンする・変異を集める、などで新しいスキンが解放されます。

## オンラインランキング

右上の「🏆 ランキング」（PCは5キー）とタイトル画面から見られます。ジャンルは
最高飛距離・毎秒の稼ぎ・累計の稼ぎ・インデックス・変異コレクション・リボーン・持ち帰った数。
名前は設定の「プレイヤー名」（空ならかるわかGAMESアカウントの表示名）。キャラを1体持ち帰ると載ります。

Supabase の `public.llb_scores` テーブルと `public.llb_submit_score` RPC を使っています（`js/ranking.js`）。
